# Zooky organization profile

- [`profile/README.md`](profile/README.md) — organization profile.
- [`profile/assets/avatar.png`](profile/assets/avatar.png) — square GitHub profile picture.
- [`profile/assets/banner.png`](profile/assets/banner.png) — wide README banner.

Artwork was created with built-in image generation using the existing Zooky mascot and brand cards as references. The avatar preserves the violet mascot, yellow antenna, cream belly, pink cheeks, and dark outlines on a cream background. The banner uses the same identity with the established tagline and the support line “Engineering. One Round at a time.”

The avatar must be uploaded separately in GitHub organization settings.

Repository: https://github.com/zooky-app/.github
